# Project page source

This static page presents the MedHorizon benchmark and its reported results.

Preview from the repository root:

```bash
python -m http.server 8000 --directory docs/site
```

Open `http://localhost:8000`. The page uses the existing project figures and links to the public paper, dataset, and repository. No build step is needed. Hosting configuration is separate from the source release; no live GitHub Pages URL is assumed here.
